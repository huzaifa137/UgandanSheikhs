Backup & reset

The prototype keeps admin changes in this browser. Download a copy, restore one, or start again.

Download a backup

Everything the admin changed: edits, new items, drafts, settings, staff, audit log and moderation records. Uploaded PDFs are not included.

Restore a backup

Replaces the current admin data with the file's contents.

Reset the admin to the demo data

Removes every admin change, including new lectures and books, settings and the audit log. Staff accounts return to the five demo accounts.
